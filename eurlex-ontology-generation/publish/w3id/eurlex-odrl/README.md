# EurLex ODRL ontology

Persistent identifiers for the ontology extracted from EUR-Lex by the
EurLex Ontology Generation project (OWL 2 + ODRL 2.2).

- Homepage / source: https://github.com/jmrozanec/eurlex-ontology-generation
- Ontology: https://w3id.org/eurlex-odrl/ontology
- SHACL shapes: https://w3id.org/eurlex-odrl/shapes
